# 通用续干

任何一框停了、卡住、对话变慢，都开新对话：先贴这段，再在下面贴它的专属开场话。

```
前一个对话停了，这是接手的新对话：接着干，不重做，不重新盘点，不自我介绍。

照下面的专属开场话做，另外守这几条：
1. 一开始用 lane_checkin(first=true) 读签到记录最后 10 行，找到最后写的“下一件”，直接从那一件接着做。要你读的其他文件，读完就开工，不要逐个写读后感。
2. 一直干：做完一件，签到一次（做了什么｜东西在哪｜下一件），马上接下一件，不要停下来等人回复。
3. 这一轮回复尽量做到最多；就算回复被截断或这一轮结束了，只要收到“继续”两个字，就从最后一次签到写的“下一件”接着干。
4. 真卡住（缺文件、缺权限、要人决定）才在签到写「卡住：缺什么」，然后先跳去做下一件能做的，不要整框停着等。
5. 手上的活做完了，就照 inbox.md 最后一节写的活源，自己接下一件。
6. 对话明显变慢、载不动时，签到写“换新对话”。

（专属开场话贴在这下面）
```
