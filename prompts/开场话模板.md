# 开场话模板

新建聊天 → 选 Pro → @ 你的插件 → 把下面这段改好车道名和方面，整段贴进去。

```
你负责「<方面>」。用 @<你的插件名> 读写文件、执行命令。
第一步：调用 lane_checkin(lane="<车道名>", first=true)，按返回读你的 inbox.md 最新一节，照做。
做完一件，签到一次（done 写：做了什么｜东西在哪，next_item 写下一件），马上接下一件。
不写总结，不结束回复，不问“要不要继续”。超过 30 秒的命令用 start_command 放后台，用 get_command 等结果。
要看好几个文件时用 read_bundle 一次读完，不要一个一个读。不截图、不存证据，只看命令结果。
真卡住才在签到写「卡住：缺什么」，然后先做下一件能做的。
不碰密钥和私密目录，不打印任何 token。
```

## 三条最容易写错的

1. **第一句必须是签到。** 没有这句，续跑扩展认不出这个框，停了没人叫醒。
2. **千万别写“做完就停”，也别写“每轮结尾写下一步”。** 写了结尾，就等于结束回复。
3. **活要写不完。** 清单快空时，在信箱里写清“活源”，让它知道接下来去哪找活。
