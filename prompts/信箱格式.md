# 信箱和清单怎么写

每个车道一个文件夹：`lanes/<车道名>/`

| 文件 | 谁写 | 干什么用 |
|---|---|---|
| `inbox.md` | 你（或总指挥 AI） | 派活。只往**末尾追加**一节，每节用 `# ` 开头；框签到时只读最新一节 |
| `backlog.csv` | 你，框也可以改 | 长期清单，列是 `id,status,task`；status 写 `待处理` 的才会被领，一次领 3 件 |
| `checkins.md` | 服务自动写 | 签到记录。对话换了，新对话靠它接班 |

派活不用进对话框：往 `inbox.md` 末尾追加一节，框下次签到就读到。

```
# 信箱｜10-31 14:00｜改派
登录页先放一放，优先修导出失败。
活源：backlog.csv 第 8 行起。
```
